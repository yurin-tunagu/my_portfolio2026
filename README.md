## このフォルダについて

Shift AI 3周年記念イベントで確認する、つなぐスタジオのポートフォリオ別案です。現行サイトは上書きしていません。

現在の実装範囲：

- トップページ
- 共通ヘッダー／モバイルメニュー
- 共通フッター
- 困りごと一覧（3カテゴリー・15件）
- 支援内容3ページ
- 漫画3話の個別ページ（10コマの開発用仮枠＋HTMLテキスト版）
- 漫画後の並列2方向導線
- 実践と制作
- プロフィール
- お問い合わせ（流入元の困りごと引き継ぎ＋入力内容の確認画面）
- プライバシーポリシーの公開前ドラフト
- 320pxからのレスポンシブ基盤
- 基本的なアクセシビリティ（スキップリンク、見出し構造、キーボード操作、フォーカス表示）

公開前に未完了の項目：

- 漫画3話の本画像への差し替え
- フォーム送信サービスの決定と実送信
- 迷惑送信対策
- 送信サービスに合わせたプライバシーポリシーの確定
- GA4／GTMの設定

フォームはローカル上で入力内容の確認まで動作しますが、外部送信しません。漫画の仮枠と公開前ドラフトを含むため、この状態では本番公開しません。

## ローカルプレビュー

このフォルダをドキュメントルートとして静的HTTPサーバーを起動します。

```bash
cd "/Users/yurin/AI用/📝AI出力/SNS発信/つなぐスタジオ_ポートフォリオ_イベント版_20260817"
python3 -m http.server 4173
```

ブラウザで `http://127.0.0.1:4173/` を開きます。

## 公開に関する制約

- GitHubへのコミット・pushは、画面確認後の明示承認があるまで行わない。
- Vercelへのデプロイと本番サイトの変更は、明示承認があるまで行わない。
- 漫画の仮枠、未実装ページ、送信できないフォームを本番公開しない。
- フォーム送信先・情報の保管方法・プライバシー文面が一致するまで外部送信を設定しない。
