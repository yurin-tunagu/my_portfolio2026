# お問い合わせフォーム 設定メモ

秘密情報ではない（合言葉は公開されるJSに入る）。片方だけ変えて不一致になるのを防ぐための控え。

## フォーム合言葉（FORM_TOKEN）

```
tng-2026-ebyoodl5i3ib12g0
```

同じ値を次の2箇所に設定する：

1. `assets/js/site.js` の `const FORM_TOKEN = "...";`
2. GAS（お問い合わせスクリプト）のスクリプトプロパティ `FORM_TOKEN`

変更するときは必ず両方そろえる。GAS側が未設定なら合言葉チェックは自動でオフ（後方互換）。

## 反映の順番

1. site.js を更新 → コミット/push → Vercel本番へ
2. GASに新コードを貼って「新バージョン」で再デプロイ
3. 最後に GAS のスクリプトプロパティ `FORM_TOKEN` を設定

（先に3をやって site.js が古いままだと、正規の送信が全部「ブロック」シート行きになる）
