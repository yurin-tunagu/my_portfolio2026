# お問い合わせフォームの送信先（Google Apps Script）

`contact-form.gs` は、サイトのお問い合わせフォームから送られた内容を
Googleスプレッドシートへ記録し、通知メールを送るためのスクリプトです。

このフォルダのコードには、メールアドレスもスプレッドシートIDも書かれていません。
どちらもGAS側の「スクリプト プロパティ」に持たせているため、
このファイルをGitHubへ上げても通知先は公開されません。

---

## 1. スクリプトを作る

1. <https://script.google.com/> を開き「新しいプロジェクト」を作る
2. プロジェクト名を「つなぐスタジオ お問い合わせ」などに変える
3. `contact-form.gs` の中身をすべてコピーして、エディタに貼り付けて保存する

## 2. 通知先メールアドレスを登録する

コードには書かずに、GASの設定側へ登録します。

1. 左メニューの歯車「プロジェクトの設定」を開く
2. 一番下の「スクリプト プロパティ」→「スクリプト プロパティを追加」
3. 次を入力して保存する

   | プロパティ | 値 |
   |---|---|
   | `NOTIFY_EMAIL` | 通知を受け取りたいメールアドレス |

## 3. 記録用スプレッドシートを作る

1. エディタ上部の関数の選択欄で `setup` を選び「実行」を押す
2. 初回はGoogleの許可画面が出るので、内容を読んだうえで許可する
3. 実行ログにスプレッドシートのURLが出るので開いて確認する
   （`お問い合わせ` シートに見出し行ができていれば成功）

## 4. ウェブアプリとして公開する

1. 右上「デプロイ」→「新しいデプロイ」
2. 歯車マークから種類「ウェブアプリ」を選ぶ
3. 次のように設定して「デプロイ」

   | 項目 | 設定 |
   |---|---|
   | 次のユーザーとして実行 | 自分 |
   | アクセスできるユーザー | 全員 |

4. 表示された「ウェブアプリのURL」（`/exec` で終わるもの）をコピーする

「アクセスできるユーザー: 全員」は、サイトを見た人がログインせずに
送信できるようにするために必要です。URLを知られても、このスクリプトは
お問い合わせを受け付ける以外のことをしません（スプレッドシートの中身を
返したり、他の情報を出したりはしません）。

## 5. サイト側に貼り付ける

`assets/js/site.js` の先頭にある次の行に、4でコピーしたURLを貼ります。

```js
const CONTACT_ENDPOINT = "";
```

貼り付けたら、キャッシュ対策のバージョンを更新して整合性チェックを回します。

```bash
python3 scripts/bump_asset_version.py 20260819-contact-endpoint
python3 scripts/check_consistency.py
```

空のままにしておくと、送信ボタンは押せないままで、外部へは何も送られません。
URLの形式（`https://script.google.com/…/exec`）と違う値を入れた場合も同じです。

## 6. 動作を確認する

ローカルサーバーを起動して、実際に1件送ってみます。

```bash
python3 -m http.server 4174
```

`http://127.0.0.1:4174/contact/` を開いて送信し、次の3つを確認します。

- 画面に「送信完了しました」が出る
- スプレッドシートに1行増えている
- 通知メールが届く

---

## コードを直したときの注意

**保存しただけでは公開中のURLに反映されません。**
「デプロイ」→「デプロイを管理」→ 鉛筆マーク → バージョンを「新バージョン」にして
更新してください。URLは変わりません。

## 迷惑送信対策の中身

| 対策 | 内容 |
|---|---|
| 見えない入力欄 | 人には見えない欄が埋まっていたら、通知せず `ブロック` シートへ記録する |
| 時間の判定 | ページ表示から3秒未満の送信を同様に扱う |
| 連投制限 | 同じメールアドレスから60秒以内の再送信と、1時間に5件を超える送信を断る |
| 入力の検証 | 必須項目・文字数・カテゴリー・困りごとIDの形式を送信先でも確認する |
| 数式の無効化 | `=` で始まる文字がスプレッドシートの数式として動かないようにする |

ブロックした内容も `ブロック` シートには残ります。
万一ふつうの利用者を巻き込んでしまっても、内容を読んで対応できます。
